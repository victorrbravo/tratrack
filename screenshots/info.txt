About Tratrack (User)

In just a few minutes, everything is organized and ready to save for your next adventure.

About TraTack (Developer)


The project has two apps. One thing is a service written in Golang. This service exposes a gRPC interface. It defines a few methods to analyze the video, receives a file ID to use in Meta Muse AI, analyzes a video, and generates a JSON file. After that, it returns the JSON via gRPC. The service also exposes another method called ‘callstories,’ which queries the stories service and searches in a database


The second app is written in Swift for macOS and iOS. It’s a UI app that lets the user upload an MP4 video to the Meta Muse AI service via gRPC. The app calls the Analyze method, which returns a JSON response after a few minutes. The UI shows the processing progress, displays the returned JSON, and allows the user to view the video inside the app. It can also modify certain information in the database based on things like location, tags, and other metadata, while keeping the video accessible within the UI.
